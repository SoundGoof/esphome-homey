Med ESPHome bygger du enkelt dine egne smarte enheter basert på ESP. ESPHome-appen for Homey kobler dem til Homey via en direkte lokal tilkobling.

Støtte for ESPHome-enheter med Light, Switch, Sensor, Binary sensor, Cover, Climate, Fan, Lock, Button, Number, Select, Media player og flere entities. Med ESPHome-appen for Homey kan du styre disse entities via Homey og i Flows, og samle inn dataene deres i Insights.

For denne integrasjonen kobler Homey seg direkte til ESPHome-enhetene dine på det lokale nettverket via Native API, med automatisk oppdagelse over mDNS.
