Avec ESPHome, tu construis facilement tes propres appareils connectés à base d’ESP. L’app ESPHome pour Homey les relie à Homey via une connexion locale directe.

Prise en charge des appareils ESPHome avec les entités Light, Switch, Sensor, Binary sensor, Cover, Climate, Fan, Lock, Button, Number, Select, Media player et plus encore. L’app ESPHome pour Homey te permet de les contrôler via Homey et dans Flows, et de collecter leurs données dans Insights.

Pour cette intégration, Homey se connecte directement à tes appareils ESPHome sur le réseau local via la Native API, avec découverte automatique via mDNS.
