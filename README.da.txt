Med ESPHome bygger du nemt dine egne smarte enheder baseret på ESP. ESPHome-appen til Homey forbinder dem til Homey via en direkte lokal forbindelse.

Understøttelse af ESPHome-enheder med Light, Switch, Sensor, Binary sensor, Cover, Climate, Fan, Lock, Button, Number, Select, Media player og flere entities. Med ESPHome-appen til Homey kan du styre disse entities via Homey og i Flows og indsamle deres data i Insights.

Til denne integration forbinder Homey sig direkte til dine ESPHome-enheder på det lokale netværk via Native API, med automatisk opdagelse over mDNS.
