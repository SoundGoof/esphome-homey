С ESPHome легко собрать собственные умные устройства на базе ESP. Приложение ESPHome для Homey подключает их к Homey через прямое локальное соединение.

Поддержка устройств ESPHome с сущностями Light, Switch, Sensor, Binary sensor, Cover, Climate, Fan, Lock, Button, Number, Select, Media player и другими. С приложением ESPHome для Homey вы можете управлять этими сущностями через Homey и в Flows, а также собирать их данные в Insights.

В этой интеграции Homey подключается напрямую к вашим устройствам ESPHome в локальной сети через Native API, с автоматическим обнаружением по mDNS.
