Med ESPHome bygger du enkelt dina egna smarta enheter baserade på ESP. ESPHome-appen för Homey kopplar dem till Homey via en direkt lokal anslutning.

Stöd för ESPHome-enheter med Light, Switch, Sensor, Binary sensor, Cover, Climate, Fan, Lock, Button, Number, Select, Media player och fler entities. Med ESPHome-appen för Homey kan du styra dessa entities via Homey och i Flows, och samla in deras data i Insights.

För den här integrationen ansluter Homey direkt till dina ESPHome-enheter på det lokala nätverket via Native API, med automatisk upptäckt över mDNS.
