Met ESPHome bouw je eenvoudig je eigen slimme apparaten op basis van ESP. De ESPHome-app voor Homey koppelt ze via een directe lokale verbinding aan Homey.

Ondersteuning voor ESPHome-apparaten met Light, Switch, Sensor, Binary sensor, Cover, Climate, Fan, Lock, Button, Number, Select, Media player en meer entities. Met de ESPHome-app voor Homey kun je deze entities bedienen via Homey en in Flows, en hun data verzamelen in Insights.

Voor deze integratie maakt Homey rechtstreeks verbinding met je ESPHome-apparaten op het lokale netwerk via de Native API, met automatische ontdekking via mDNS.
